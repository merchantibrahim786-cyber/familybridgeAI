# 🏠 FamilyBridgeAI

FamilyBridgeAI is an AI-powered family management platform that helps families communicate better, stay organized, manage chores, track expenses, preserve memories, and strengthen relationships.

## 🚀 Features

### 🧠 Private AI Workspace
- Talk privately with an AI assistant
- Receive emotional support and advice
- Store personal conversations securely

### 📬 Family Messaging System
- Send respectful messages to family members
- AI rewrites emotional messages into polite communication
- Separate inbox for each family member

### 🏠 Smart Chore Management
- Add and claim household chores
- AI assigns difficulty points automatically
- Photo verification prevents cheating
- Reward point system

### 📅 Shared Family Calendar
- Add events and milestones
- Manage schedules together
- Track important family activities

### 📸 Memory & Activity Hub
- Store family memories
- Weekend activity planner
- Digital family journal

### 💖 Hugs & Heart Wall
- Track family hugs
- Post appreciation messages
- Encourage positive family interactions

### 💳 Health Budget Tracker
- Track family expenses
- Log medical costs
- Receipt scanner with AI

### 📊 Weekly Harmony Report
- AI-generated family performance reports
- Tracks chores, interactions, and spending

## 🛠 Technologies Used

- Python

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/FamilyBridgeAI.git
cd FamilyBridgeAI
```

2. Install dependencies

```bash
pip install streamlit google-generativeai pillow
```

3. Add your Gemini API key to Streamlit Secrets

```toml
GEMINI_API_KEY="YOUR_API_KEY"
```

4. Run the application

```bash
streamlit run app.py
```
